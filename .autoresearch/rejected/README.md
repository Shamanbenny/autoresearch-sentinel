# Rejected Experiments

This directory holds local archives of rejected attempts, including the
candidate project snapshot, `PROGRAM.md`, `LOGBOOK.md`, `RESULT.json`, and raw
evaluation output. Keeping these artifacts available locally can help diagnose
failures or revisit an idea under changed conditions.

Contents other than this README are gitignored and are not part of the durable
project history. Summarize reusable conclusions in the root `LOGBOOK.md`.
