# Approved Experiments

Sentinel stores full project snapshots for the initial baseline and each
approved experiment here. `V1-0/project/` is the initial baseline snapshot;
later folders such as `V1-1/project/` contain the complete cumulative project
at that approved version. Each version also stores its `RESULT.json`, metric
result, command logs, and declared evaluator artifacts. `baseline.json` records
the active baseline measurement; `state.json` tracks the latest approved
snapshot and next candidate version. This directory is version-controlled.
Preserve these snapshots so the current best project and its evidence remain
reviewable.

No Sentinel-managed baseline or candidate snapshots have been created yet.
